# Минималистичный сайт для розыгрыша

## Структура
- `index.html` — первая страница с одной кнопкой.
- `image/index.html` — отдельная страница, на которую ведёт кнопка.
- `image/picture.jpg` — сюда положите свою картинку.

## Как вставить свою картинку
1. Откройте папку `image`.
2. Скопируйте туда свою картинку.
3. Назовите файл `picture.jpg`.
4. Если картинка в PNG или WebP, откройте `image/index.html` и замените `src="picture.jpg"` на имя файла, например `src="picture.png"`.

## Бесплатная публикация через GitHub Pages
1. Создайте или войдите в аккаунт на https://github.com/.
2. Создайте новый публичный репозиторий, например `surprise-site`.
3. Загрузите в репозиторий содержимое этой папки так, чтобы `index.html` находился в корне репозитория, а папка `image` — рядом.
4. В репозитории откройте **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Подождите несколько минут. На странице Pages появится публичный адрес вида `https://ВАШ-ЛОГИН.github.io/surprise-site/`.
7. Отправляйте этот адрес. Кнопка ведёт на отдельную страницу картинки: `https://ВАШ-ЛОГИН.github.io/surprise-site/image/`.

## Важно
- Публичный сайт означает, что любой, у кого есть ссылка, потенциально может открыть страницу и изображение.
- Не загружайте личные, конфиденциальные или чужие изображения без разрешения.
- Не отправляйте ссылку, пока не проверили, что картинка отображается и адреса работают.
